Note:

The following keywords in the file hit indicate different hypothesis testing methods
  ttest: Student's t test
  wtest: Wilcoxon rank-sum test
  anova: Analysis of Variance
  kruskaltest: Kruskal-Wallis test
  kruskaldunntest: Dunn's test
  auto: Student's t test were used when the data follow a normal distribution, otherwise Wilcoxon rank-sum test
